# DDoS Testing Tool

Simulates DDoS (Distributed Denial of Service) attacks against specified targets, for authorized security testing.

## Installation

```bash
git clone https://github.com/fcarvajalbrown/ddos-detection.git
cd ddos-detection
pip install -r requirements.txt
```

## Usage

```bash
python src/main.py
```

See `docs/user_guide.md` for details and `docs/architecture.md` for how it's built.
